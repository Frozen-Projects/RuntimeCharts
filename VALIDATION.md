All sixteen automation suites passed with zero test errors or warnings. They check all chart types at multiple sizes; shared and independent axes; invalid, negative, missing, and extreme values; smooth-curve bounds; annular and angular masks; overlaid radar input; area sample context within whole-series targets; DPI-scaled pointer positions; mouse press/release cancellation; touch-handler calls; Blueprint-visible configuration and dispatchers; resource release/rebuild; local hit queries after real UMG layout; and creation/rendering of `UChartsDemoWidget` through `CreateWidget`.

The v1.0.1 regression verifies zero, one, two, and three configured ranges with three series across vertical/horizontal bar, line, area, and combo charts. Two configured ranges produce exactly two sets of value-axis tick labels. Additional series share the first displayed range, including its automatic fallback when bounds are invalid. Bar geometry is checked against that range, and radar's existing per-spoke fallback is preserved.

The v2.0.0 regressions compare combo bars against standalone bar geometry for two series and three categories, with signed values and independent ranges. They exercise vertical/horizontal orientations, sharp/smooth lines, two bar spacings, and two thickness/radius combinations. Each marker is checked against its own bar tip, each line endpoint against its matching marker, and each part against its configured primary/secondary color. Missing samples remain disconnected. Input checks cover transitions between bar and line at the same data indices, part-specific click colors, and mismatched-part click cancellation.

Reflection checks confirm that every widget exposes the correct style struct and setter, that unsupported style fields are absent, and that the old value `Color` property redirect resolves to `PrimaryColor`.

The rendered style test updates the same `UChartsComboWidget` through its public setter between captures. Secondary-colored pixels increase from **315** with thickness 1/radius 2 to **4,903** with thickness 8/radius 2, then **7,240** with thickness 8/radius 10. This verifies that both public style controls change the actual UMG output after initial layout.

The v2.1.0 padding regression measures text with Slate and checks the requested gap against actual label positions for vertical/horizontal bars, one/two/three axes, radar spoke names, and the legend. It verifies that hidden legends reserve no gap and invalid padding is sanitized.

Area regressions verify one compound target per series, sharp/smooth irregular fills, concave notches, negative lobes, disconnected runs, overlap ordering, transparent-fill behavior, stable hover identity across distant samples, current sample context, and same-series click behavior. Every rendered fill-triangle interior is checked against its series hit mask. Native UMG pixel captures confirm that hovering one lobe highlights another distant lobe while a concave gap and a separate opaque series remain unchanged. The same render test updates a bar's padding through its public setter after initial layout and checks its updated hit geometry.

The gallery was generated by **Unreal Engine**, with a floating-point linear render target and a single conversion to sRGB for PNG export. The screenshot test checks both visible data pixels in all eight tiles and the configured background color. It is not a browser recreation or an AI-generated mockup.

`Documentation/RuntimeCharts-AreaHoverAndPadding.png` is a second native capture showing the area before/after hovering and bar layouts with different axis/legend padding settings.

## Scope

- Shipping was compiled and linked. A packaged/cooked game was not launched.
- Input tests call the native Slate mouse/touch handlers with constructed events. Physical touch devices were not tested.
- Blueprint reflection, runtime setters, and color redirect registration were tested. An authored Widget Blueprint asset was not compiled or migrated as part of this source-only delivery. Existing style nodes need updating to the typed structs described in the README.
- Android, Quest, macOS, Linux, Widget Components, Retainer Boxes, high-volume streaming performance, and long-duration use were not validated.
- Unreal's toolchain reports MSVC 14.51 as newer than its preferred version. The updated plugin source compiled without deprecation diagnostics.

## Reproduce

Install the plugin in a C++ project, build its Editor target, and run the **RuntimeCharts** automation group. For unattended validation, supply these arguments to `UnrealEditor-Cmd.exe` after the `.uproject` path:

```text
-unattended -nop4 -nosplash -RenderOffscreen -NoSound
-ExecCmds="Automation RunTests RuntimeCharts"
-TestExit="Automation Test Queue Empty"
-ReportExportPath="<absolute report directory>"
-ChartsOutput="<absolute image directory>"
```

Check the exported report's test count and individual results. A zero editor process exit code alone does not establish that tests passed.
